# AeroSight: Aerial Object Detection & Surveillance Dashboard

**AeroSight** is an end-to-end aerial surveillance and object detection platform powered by **YOLO Oriented Bounding Boxes (OBB)** trained on the **DOTA v1.0** dataset. It features an asynchronous high-performance **FastAPI** backend with sliding-window tiled inference, rotated polygon non-maximum suppression (NMS), temporal change detection, and a **React + Vite + TypeScript + Tailwind CSS** surveillance dashboard.

---

## Key Features

1. **Oriented Bounding Boxes (YOLO-OBB)**:
   - Detects arbitrarily oriented aerial objects across the 15 DOTA v1.0 classes (`plane`, `ship`, `storage-tank`, `baseball-diamond`, `tennis-court`, `basketball-court`, `ground-track-field`, `harbor`, `bridge`, `large-vehicle`, `small-vehicle`, `helicopter`, `roundabout`, `soccer-ball-field`, `swimming-pool`).
   - Uses 8-coordinate oriented polygons `(x1, y1, x2, y2, x3, y3, x4, y4)` to fit objects tightly regardless of flight angle or docking orientation.

2. **Tiled Inference & Rotated Polygon NMS**:
   - Handles massive aerial orthophotos (>10,000px) by slicing into 1024x1024 tiles with 200px overlap.
   - Merges detections across tile boundaries using exact Shapely polygon Intersection-over-Union (IoU) NMS, eliminating duplicate boundary detections.

3. **Bi-Temporal Change Detection**:
   - Compares surveillance sweeps of the same coordinate zone across time.
   - Highlights new assets in **Neon Green**, missing assets in **Crimson Red**, and persistent infrastructure in subtle gray.
   - Outputs quantitative count delta matrices per class.

4. **Real Evaluation Metrics & Training Curves**:
   - Metrics (mAP50, mAP50-95, precision, recall, confusion matrix, training loss) are generated by actual evaluation scripts on real DOTA validation data.
   - Fallback mechanism to pre-trained weights ensures immediate out-of-the-box demonstration.

5. **Premium Black Aesthetic Dashboard**:
   - Engineered with an ultra-sleek, dark military-grade aesthetic (`#090a0f` canvas, `#12131a` inner surface, `#181924` dark cards), electric neon accents, grouped bar charts, real-time alert feed, and dedicated Detection and Change Detection workspaces.
   - For an in-depth technical breakdown and live demonstration script, refer to [PROJECT_GUIDE.md](PROJECT_GUIDE.md).

│   ├── inference.py         # Sliding-window tiled OBB engine + Rotated NMS
│   ├── change_detection.py  # Temporal difference analysis engine
│   ├── database.py          # SQLite persistence for runs and surveillance alerts
│   ├── samples/             # Curated DOTA validation demo scenes
│   └── static/              # Storage for annotated runs & confusion matrices
├── frontend/                # React + Vite + TypeScript + Tailwind dashboard
│   ├── src/
│   │   ├── components/      # Sidebar, TopBar, Footer

## Quick Start (One-Command Launch)

### On Windows
Double-click `run.bat` or execute in command prompt:
```cmd
run.bat
```

### On Linux / macOS
```bash
chmod +x run.sh
./run.sh
```

The system will start:
- **Frontend Dashboard**: [http://localhost:5173](http://localhost:5173)
- **Backend API Docs**: [http://localhost:8000/docs](http://localhost:8000/docs)

---

## Manual Execution

### 1. Backend Server
```bash
cd backend
python -m uvicorn main:app --host 127.0.0.1 --port 8000
```

### 2. Frontend Server
```bash
cd frontend
npm install
npm run dev
```

## Machine Learning Pipeline

### Smoke Test (1 Epoch)
```bash
python ml/train.py --data ml/data_smoke.yaml --epochs 1 --batch 2 --imgsz 1024
```

### Full Evaluation
```bash
python ml/evaluate.py --data ml/data.yaml --imgsz 1024
```

## API Endpoints

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `POST` | `/api/detect` | Runs tiled YOLO-OBB detection on uploaded or sample image |
| `POST` | `/api/change-detection` | Compares before/after temporal image pair |
| `GET` | `/api/metrics` | Retrieves real mAP50, precision, recall, and training curves |
| `GET` | `/api/history` | Fetches logged surveillance runs and summary counts |
| `GET` | `/api/alerts` | Fetches active surveillance alert notifications |
| `GET` | `/api/models` | Lists available weights and active model |
| `POST` | `/api/models/select` | Switches active inference model |
| `GET` | `/api/samples` | Lists pre-loaded DOTA validation images |
